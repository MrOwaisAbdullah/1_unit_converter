# Multi-Unit Converter

An interactive Python CLI application for seamless unit conversion across length, weight, temperature, and volume metrics.

## 🌟 Features
- **Length**: Meters, Kilometers, Miles, Feet, Inches.
- **Weight**: Kilograms, Grams, Pounds, Ounces.
- **Temperature**: Celsius, Fahrenheit, Kelvin.
- **Volume**: Liters, Milliliters, Gallons.

## 🛠️ Tech Stack
- **Language**: Python 3
- **Tooling**: `uv`

## 🚀 Getting Started
```bash
git clone https://github.com/MrOwaisAbdullah/1_unit_converter.git
cd 1_unit_converter
python main.py
```
